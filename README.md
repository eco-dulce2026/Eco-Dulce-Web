# Eco-Dulce

Pagina web del videojuego Eco-Dulce (hecho en RPG Maker XP). Trata sobre la contaminacion en Moniquira, Boyaca.

Archivos:
- index.html: todas las secciones de la pagina
- css/style.css: estilos
- js/script.js: menu, carrusel, ventana de los ODS y boton de descargar (ARCHIVO_DESCARGA)
- descargas: aqui va el archivo del juego
- img: imagenes

Para cambiar las diapositivas del carrusel se edita la lista SLIDES en js/script.js.
Para ver la pagina solo hay que abrir index.html en el navegador.
